# Customer Churn Prediction

## 📌 Description
This project focuses on predicting customer churn using machine learning. It analyzes customer data such as tenure and monthly charges to determine whether a customer is likely to leave a service.

## 🎯 Objective
To help businesses identify customers who may stop using their service and take actions to retain them.

## 🛠️ Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## 🔍 Process
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature selection
- Model building using Logistic Regression

## 📊 Result
The model achieved around 80% accuracy in predicting customer churn.
